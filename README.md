# Rishi Raj — Retro Portfolio

A retro Windows/pixel-style personal portfolio for Rishi Raj.

## Included
- Retro boot screen and Windows-style layout
- Larger 7:9 passport-style profile photo
- About, Skills, Projects, Education, Experience and Contact sections
- Skills: Python, DSA, IoT / Embedded, MATLAB, Git / GitHub
- Five main projects
- Education details based on the supplied LinkedIn screenshot
- Contact buttons for email, GitHub, LinkedIn and Instagram
- EMAIL ME copies the email address instead of opening a new Chrome page

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Upload the complete folder to a GitHub repository and enable GitHub Pages from the repository settings.

## Files
- `index.html` — portfolio structure/content
- `style.css` — retro styling and responsive layout
- `script.js` — boot animation and email-copy interaction
- `assets/rishi-profile.jpeg` — passport-style profile image
